# Retro suite

A retro-computing suit: a themed Windows experience plus retro-feeling web apps for Gemini/Google, Spotify, YouTube, Reddit, and more.

This is the main point of the repo. If you want the whole setup, start with [RETRO_SETUP.md](RETRO_SETUP.md).

- [RETRO_SETUP.md](RETRO_SETUP.md) — the full walkthrough: ISO, Node, extract the zip, run `setup.cmd`, and the project rundown.
- [windows/README-WINDOWS.md](windows/README-WINDOWS.md) — the Windows mirror: prerequisites, launch table, and what was converted for Windows.
- [EDGE_CASES.md](EDGE_CASES.md) — known breakage and fixes for the eXPerience Firefox skin, plus the pre-extracted Firefox build.

The smaller subfolders each have their own `START.md`, but the retro suit is meant to be used together.
